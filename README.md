# Random Color Generator
An interactive JavaScript project that generates random colors and keeps track of previously generated colors for quick reuse.

##  Live Demo

[ https://random-color-generator.vercel.app](https://random-color-generator-faseehansariis-projects.vercel.app/)

##  Features

*  Generate random colors on button click
*  Displays RGB color code dynamically
*  Stores last 5 generated colors
*  Click any previous color to reuse it


##  Technologies Used

* HTML
* CSS
* JavaScript (Vanilla JS)

##  How It Works

* Clicking the button generates a random RGB color
* The UI updates:

  * Background preview box
  * RGB value display
* The color is stored in a list 
* Clicking a stored color:

  * Reapplies it to the preview
  * Updates the RGB display
